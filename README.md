# Meu Portfólio 💻

Este projeto consiste em um portfólio pessoal desenvolvido para apresentar minhas informações, formação acadêmica, competências e projetos.

# 🚀 Tecnologias utilizadas

- HTML5
- CSS
- JavaScript

# 📁 Estrutura do projeto

- `index.html`: estrutura da página.
- `css/`: arquivos de estilização.
- `js/`: arquivos JavaScript.
- `img/`: imagens utilizadas no projeto.

# 🎯 Objetivo

Praticar e aprimorar meus conhecimentos em desenvolvimento web, utilizando HTML, CSS e JavaScript para criar uma página pessoal.
